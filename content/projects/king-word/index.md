A responsive, bilingual (English/Arabic) web platform built during a 1-month remote web developer internship at Instar for King Word Building Contracting LLC, based in Dubai, UAE.

### Key Highlights
* **Bilingual Experience:** Implemented full English and Arabic localization with smooth layout switching and accessible typography using Next.js and Tailwind CSS.
* **Content Management:** Integrated Sanity headless CMS, allowing dynamic content management for company services and portfolios.
* **Forms & Validation:** Developed interactive career application and inquiry forms using React Hook Form and Zod schema validation.
* **Database & File Uploads:** Connected forms to Supabase (PostgreSQL) with automated file attachment handling and email dispatch.
* **Analytics & Privacy:** Integrated Google Analytics 4 with a GDPR/ePrivacy compliant cookie consent banner adhering to Consent Mode v2 standards.
