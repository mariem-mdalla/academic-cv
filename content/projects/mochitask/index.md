A solo full-stack Kanban productivity application designed for streamlined task management and workflow organization.

### Key Highlights
* **Interactive Kanban Board:** Real-time task tracking across custom status workflows (To Do, In Progress, Done).
* **Robust REST API:** Full CRUD operations engineered with Node.js and Express, connected to a cloud-hosted MongoDB Atlas database.
* **Modern UI/UX:** Built with React, TypeScript, and Tailwind CSS for responsive and responsive task operations.
* **Live Deployment:** Deployed and accessible on Vercel.
