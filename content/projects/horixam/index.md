A comprehensive university exam management platform built for academic institutions, emphasizing deep security engineering and role-based management.

### Key Highlights
* **Multi-Layer Security Architecture:** Implemented RS256 JWT asymmetric token authentication, refresh token rotation, bcrypt password hashing, and brute-force protection.
* **Role-Based Access Control (RBAC):** Unified dashboards tailored for students, professors, and academic administrators.
* **API Hardening:** Applied production-grade middleware protection with Helmet.js, strict CORS configuration, and request rate limiting.
* **Data Layer:** Modeled relational data schemas with PostgreSQL and Sequelize ORM for transactional integrity.
